# Изменения

## [Unreleased]

### Несовместимо

- FIN-277: OpenPools и Pools.Ping возвращают context.Canceled / context.DeadlineExceeded, только когда закончился контекст вызывающего (ctx.Err()); таймаут подключения драйвера при живом контексте (connect_timeout в DSN, молчащий primary) теперь ErrPoolUnavailable, а в v0.2.0 был context.DeadlineExceeded. Сервисам: проверить обработчики errors.Is(err, context.DeadlineExceeded / context.Canceled) после OpenPools и Pools.Ping — недоступная БД с connect_timeout попадёт в ветку ErrPoolUnavailable. В шаблоне и сервисах на 25.10.2026 таких ветвлений нет (ошибка старта возвращается как есть, readiness учитывает только err != nil), правки не требуются. Текст и цепочка ошибок драйвера по-прежнему не возвращаются; API не менялся.

## [v0.2.0] — 2026-10-25

### Добавлено

- FIN-253: явный lifecycle primary/replica pools через OpenPools, безопасные ошибки подключения и повторяемый Close; прежний New(pool) сохраняет владение пула у вызывающего. Маршрутизация чтения и границы транзакций остаются у сервиса; API Run/RunMapped и опубликованные теги не менялись.

### Изменено

- FIN-254: подготовлен выпуск v0.2.0 с накопленными изменениями; записи перенесены из Unreleased в версионную секцию до публикации тега. Runtime, API и зависимости этим PR не меняются.

- FIN-243: независимые statements-профили unit/integration/API и обязательные пороги80 с готовым go-test-coverage v2.20.1; guards пустых/пропущенных наборов, исполнение Example/Fuzz и проверки публичного Go API. Только тестовый пакет internal/pgtest исключён из одинакового знаменателя всех трёх уровней; его тесты продолжают выполняться. Runtime и экспортируемый API не менялись.

### Исправлено

- FIN-242: восстановлена история опубликованного v0.1.2 и уточнена подготовка следующих выпусков; каждый PR библиотеки добавляет запись в CHANGELOG, включая документацию, тесты и CI. Содержимое опубликованных тегов не менялось.
